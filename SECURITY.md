# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or discussions. If private vulnerability reporting is enabled for this repository, use the **Security** tab on GitHub to send a report privately. Otherwise, contact the repository owner through their GitHub profile and ask for a private reporting channel before sharing exploit details.

There is no guaranteed response-time SLA for this project. Do not include real credentials, personal financial data, or active access tokens in a report.
